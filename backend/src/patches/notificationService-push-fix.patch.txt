=== CHANGE 2: Add delivery logging helper ===
Add this AFTER the FcmPayload interface:

  private static pushDeliveryLog: Array<{ts: string; event: string; userId: string; sent: number; failed: number; cleaned: number}> = [];

  private static logDelivery(event: string, userId: string, result: {sent: number; failed: number; cleaned: number}): void {
    const entry = { ts: new Date().toISOString(), event, userId, ...result };
    this.pushDeliveryLog.push(entry);
    if (this.pushDeliveryLog.length > 200) this.pushDeliveryLog.shift();
    console.log(`[PUSH-DELIVERY] ${JSON.stringify(entry)}`);
  }

=== CHANGE 3: Update sendFcm to use sendPushAndCleanup ===
OLD:

      if (tokenList.length > 0) {

  }
